~~~~markdown
**No bypass.**

-   Connector credentials and protected data (for example `payroll.csv`) are held only by the gateway and the connector services. Agents hold only their own gateway credential. ~~~~
~~~~

## Steps

1. Plan first. Use the Postgres image pinned in `docs/VERSIONS.md`.
2. Define a PostgreSQL service with credentials read from `.env` and a named volume.
3. Define two networks: one the agent runtime may join, and one `internal: true` network for the gateway and connectors. The connectors service itself arrives in T1.4. Do not create it now.
4. Do not publish any connector port to the host.
5. Prove the isolation: start a throwaway container on the agent network and another on the internal network, then show that the first cannot reach the second.
6. Add the run steps to the README.
