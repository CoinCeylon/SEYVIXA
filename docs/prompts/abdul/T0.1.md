## Steps

1. Plan first. List assumptions (for example which Node LTS line is current).
2. Check the current versions in the official docs or release pages. Do not use model memory. Pin Node LTS, TypeScript, pnpm, Fastify, zod, Next.js, Tailwind and the Postgres image in `docs/VERSIONS.md`, with the source link for each.
3. Create the monorepo layout from guide Section 4.1 with empty placeholders.
4. Write `.gitignore` (at least `.env`, `node_modules`, build output, any private key path). Write `.env.example` with fake values only.
5. Write a README stub with the run steps you can already verify.
6. Clone into a new empty directory and follow the README. Fix gaps.
7. Run `git ls-files` and check that no secret or key file is tracked. Commit small commits with `type(scope): message`.
